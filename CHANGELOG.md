# Changelog

Release summaries for Master Class Diagnostics Workbench. See [release notes](Docs/Releases/README.md)
for downloads and setup, or [commit history](https://github.com/dmccalla/BigFix-Master-Class-2026/commits/main/) for implementation details.

## [Unreleased]

## [2.2] - 2026-11-02

- Expand Client Performance property evaluation and client-setting context. Name the delivered Excel worksheet when a report preview is shortened and retain the complete dataset.
- Standardize health score bands and apply the approved PerfMon and FillDB assessment criteria. Preserve analyzer measurements and explain missing or unassessed evidence.
- Improve deployment collection diagnostics, pacing, partial-capture handling, and automatic logging cleanup.
- Correct Mini Report explanations, charts, tables, and pagination. Stop runs when required output is missing or a module fails.
- Strengthen credential handling, input limits, workbook text handling, and local data processing.
- Include the shared practice dataset with 2,537 clients and a separate large PerfMon download with neutral identifiers.
- Update the Word/PDF user and lab guides, delivery instructions, and Windows launcher setup.

## [2.1] - 2026-10-15

- Add dark mode and publish the student User Guide in Word and PDF.
- Improve evaluation-name resolution, analysis matching, and support for partial Client Performance captures.
- Correct Client Loop score bands, minimum-interval reporting, and collector consistency.
- Reject reversed date ranges and document how to unblock downloaded Windows launchers.

## [2.0]

- Introduce Client Performance, PerfMon, and FillDB modules with Mini Reports, infographics, and Excel workbooks.
- Provide the desktop workflow, Windows launcher, practice dataset, and collection guides.
- Keep complete relay and subnet data in workbooks while showing concise report previews.
- Correct collection queries, FillDB assessment explanations, and failed-output handling.
- Support legacy Excel inputs and distribute release packages with an SBOM and checksums.
