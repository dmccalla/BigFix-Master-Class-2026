# Master Class Diagnostics Workbench 2.2

**Status:** Released
**Release date:** 2026-11-02

This release updates the student Workbench while keeping the Client Performance, FillDB and PerfMon workflow. Use the included guide and the sample folder shipped with this version.

## What changed

- Includes one complete practice dataset shared with the other workbenches: 2,537 client records and 24 relays. No separate class-results download is needed.
- Names the delivered workbook and worksheet when a Client Performance list exceeds the report preview. The workbook retains the complete dataset.
- Verifies FillDB scores against known results and preserves the analyzer's data. A capture with no assessed guide checks remains Not Assessed; the normal sample produces Healthy, 100 of 100.
- Adds a what-to-deliver table to the current User Guide and includes its Microsoft Word PDF export.
- Keeps runtime folders at the ZIP root and ships PDF-only documentation. START_HERE explains setup and launcher unblocking.
- Provides a separate large PerfMon companion using neutral embedded server identifiers. Its actual capture duration is 20:51:07 with 1,252 readings; the guides call it a 24-hour sample.

## Download and start

1. Download `Master-Class-Diagnostics-Workbench-2.2.zip` and its `.sha256` file.
2. Extract the application ZIP and open `START_HERE.txt`.
3. Read the included User Guide and run the launcher from `Launchers` on Windows. Python 3.12 or newer is required.
4. For the larger PerfMon example, extract `Sample-Data-Perfmon-Large-2.2.zip` into the same application folder. Select its BLG under `SampleData/Large_Perfmon` directly in the PerfMon module. The normal sample stays separate.

Review generated findings and complete the consultant assessment before handing reports to a customer. A short lab capture tests collection and processing; it does not replace the required assessment observation period.
